# The Margin

An editorial-style blog built with React + Vite.

## Getting started

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

This builds the project and publishes the `dist` folder to the `gh-pages` branch.

## Tech stack

- [React 18](https://react.dev/)
- [Vite 5](https://vitejs.dev/)
- [gh-pages](https://github.com/tschaub/gh-pages)
- [Tabler Icons](https://tabler.io/icons)
- [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) + [DM Sans](https://fonts.google.com/specimen/DM+Sans)
